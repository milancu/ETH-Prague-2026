00Co to je & jak to funguje

Hra. Teď se zavážeš (commit) k losování v budoucím čase. Výsledek je plně určen blokem SpaceComputer beacon (cosmic radiation), který v ten okamžik vznikne — nikdo ho nemůže předem znát ani vybrat.

Výstup: jedna kostka 1–6, rovnoměrně, P(každé) = 1/6.

Postup: (1) Commit teď → vygeneruje SHA-256 hash, který publikuj veřejně. (2) Počkej, až vznikne cílový beacon blok (1 blok / minutu). (3) Reveal: kdokoliv stáhne ten blok a deterministicky dopočítá výsledek.

Přesný algoritmus odvození 
raw    = bytes(ctrng[0]) || bytes(ctrng[1]) || bytes(ctrng[2])
seed   = SHA256(raw)                                       // 32 bytes
stream = SHA256(seed || u32be(0)) || SHA256(seed || u32be(1)) || ...
draw bytes from stream; accept b iff b < 252               // rejection sampling
roll   = (b % 6) + 1
die    = first accepted byte
Result (1..6) = die

01Commit

Beacon vydává 1 blok / minutu, takže minimum je 1.
